## Questions to answer from your recording or transcript

1. How many AI answers did I accept unchanged? Edited? Rejected?
2. Name one thing the AI got wrong. When did I notice? Could I have noticed
   sooner?
3. Did I check that every function the AI used actually exists?
4. Did any test I accepted pass for the wrong reason?
5. Did I write my context before my first prompt? What was missing from it?
6. Did I ask a clarifying question about the task? Should I have?
7. Where did I go silent for too long?
8. Is my PR description true? Does "What I did NOT verify" match reality?
