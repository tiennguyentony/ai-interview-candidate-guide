# FAQ

**Can I use any AI tool?**
Yes: Claude, ChatGPT, Copilot, Cursor, or anything else you use normally.
The tool isn't scored; what you do with its output is. A free chat tool with
copy-paste is enough.

**Can I use Google, docs and Stack Overflow too?**
Yes. Checking official documentation is a good sign, not cheating.

**What if I don't know the language or framework?**
That's fine. The practice repos use TypeScript and Python, and the code is
written to be readable. Interviewers care about how you explore and check,
not whether you've used that framework before. Say what you don't know and
how you're finding out.

**Do I have to finish all the exercises?**
No. Nobody finishes. Doing fewer things properly beats rushing through all
of them. Say what you skipped and why.

**What if the AI gives me the right answer immediately?**
Great, but you still need to show it's right. "The AI said so" is not
evidence. Check it and say how you checked.

**What if I find something the exercise didn't ask about?**
Mention it briefly ("I also noticed X; I'll note it and come back if there's
time"), then carry on with the task.

**What if I think something is not a bug?**
Say so, with evidence. Some tickets describe behaviour that is deliberate.
Recognising that is part of the test.

**What if my AI tool stops working?**
Tell the interviewer and switch to a backup chat tool. You won't lose points
for a tool outage.

**Should I say which parts the AI wrote?**
Yes, always. Being open about AI use is part of the honesty score, and real
teams increasingly expect it.

**Can I look at the practice repos before my mock?**
You can install one to check your setup (see
[practice-repos.md](practice-repos.md)). But don't explore the repo chosen
for your mock beforehand: exploring unfamiliar code is the skill being
tested, and if you already know the answers the mock can't help you
improve. Practise on open-source repos and the [practice/](practice/README.md)
exercises instead.

**What if I disagree with the interviewer?**
You can, politely, with reasons. Interviewers sometimes push back on
purpose to see whether you can defend a well-checked answer.

**What if I freeze or get stuck?**
Say what you're trying and what you've ruled out. Ask for a hint. Getting
unstuck with a hint is far better than silence.

**How long until I get feedback?**
Usually within 48 hours. Fill in [self-review.md](self-review.md) before you
read it, then compare.

**Are these mocks like real company interviews?**
They are modelled on how many companies now run "use your tools" rounds:
an unfamiliar codebase, AI allowed, and a focus on judgment and
verification. Formats vary by company, so ask recruiters what to expect.
