# Practice exercises

Eight short exercises you can do on your own, with answers in
[solutions.md](solutions.md). Each takes 5–15 minutes.

They are built like real interview tasks: there is some code, and often an
AI answer about it. Your job is to decide what is true and **show how you
know**.

How to use them:

1. Do the exercise **before** opening the solutions. Write your answer down.
2. You may use AI, the way you would in an interview. But note what it said
   and whether it was right.
3. Where you can, run the code. Several exercises are designed so that
   running it settles the question faster than arguing about it.
4. Compare with the solution. Score yourself: did you find the main point?
   Did you prove it, or just claim it?
